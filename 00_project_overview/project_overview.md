# IBM HR Analytics – Employee Attrition & Performance Analysis (Python)

## 1. Project Background
Employee attrition is a major challenge for organizations, leading to increased hiring costs, loss of skilled talent, and reduced productivity.  
Understanding the factors that influence employee attrition helps HR teams design better retention strategies and improve employee satisfaction.

This project analyzes employee attrition and performance data using **Python**, focusing on data cleaning, exploratory analysis, and advanced analytics to extract actionable business insights.

---

## 2. Business Problem
The HR department wants to answer the following questions:
- Why are employees leaving the organization?
- Which factors contribute most to attrition?
- Are certain roles, departments, or experience levels more vulnerable?
- How can attrition be reduced through data-driven decisions?

---

## 3. Dataset Description
- **Dataset Name:** IBM HR Analytics Employee Attrition & Performance
- **Source:** Kaggle
- **Records:** 1,470 employees
- **Features:** 35 employee attributes

### Key Data Categories:
- Demographics (Age, Gender, Marital Status)
- Job Information (Department, Job Role, Job Level)
- Compensation (Monthly Income, Salary Hike)
- Work Environment (OverTime, WorkLifeBalance)
- Performance & Satisfaction Metrics
- Target Variable: **Attrition (Yes / No)**

---

## 4. Project Objectives
- Load and clean HR employee data using Python
- Perform exploratory data analysis (EDA)
- Identify key drivers of employee attrition
- Compare insights derived using SQL vs Python
- Apply advanced Python analysis techniques
- Generate business-focused recommendations for HR teams
