# IBM HR Attrition Analysis using Python

This project analyzes employee attrition using the IBM HR Analytics dataset.
The goal is to identify key factors influencing attrition and provide
actionable business insights using Python.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## Dataset
IBM HR Analytics Employee Attrition & Performance Dataset (Kaggle)

## Status
Project setup completed. Analysis in progress.

## Model Explainability (SHAP)

To ensure transparency and business trust, SHAP (SHapley Additive Explanations)
was used to explain employee attrition predictions.

The SHAP analysis highlights key drivers such as:
- Overtime
- Monthly Income
- Total Working Years
- Job Satisfaction
- Years with Current Manager
